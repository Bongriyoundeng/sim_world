# ai/experiments/ — 헤드리스 실험

화면 없이 코어(`dongne_core` Python 바인딩)를 돌리는 재현 가능한 실험 스크립트입니다. 노트북 대신 스크립트로 두고, 같은 시드면 같은 결과가 나옵니다.

```sh
# core/crates/py/README.md대로 바인딩을 설치한 뒤, 저장소 루트에서
core/crates/py/.venv/Scripts/python ai/experiments/road_closure.py --top 5 --out ai/experiments/results/road_closure.md
```

### 읽는 법

- **도로 하나를 막아도 모두 도착**했지만 평균 통근 시간은 4~16% 늘었습니다.
- **상위 1~4위는 같은 통복로 축의 이어진 구간**입니다. 같은 2,718개 통행(전체의 80%)이 이 축을 지나므로, 지금 구역 배치에서는 주거(남서) ↔ 업무·상업(역 앞·동쪽) 통근이 통복로 한 축에 몰립니다. 2~4위를 막으면 같은 우회로를 쓰게 되어 결과가 똑같습니다(+30.7초).
- 1위(엣지 421)는 같은 축이지만 막았을 때 쓸 수 있는 우회로가 더 짧아 증가 폭이 절반(+15.1초)입니다. **가장 붐비는 도로가 가장 중요한 도로는 아니라는** 점을 보여 줍니다.
- 원평로(secondary, 2+2차선)는 차선이 많아 우회 수요를 흡수하기 쉬워 증가 폭이 가장 작습니다(+8.3초).
- 통과 차량 수만으로 상위를 고르면 같은 축의 구간이 겹칩니다. 다음 실험에서는 서로 다른 도로(OSM way)별로 하나씩 고르거나, 구간을 막았을 때의 증가 폭으로 순위를 매기는 편이 정보가 많습니다.

### 한계
