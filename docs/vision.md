# 비전

"실제 동네를 불러와 정책을 바꾸면 AI 시민이 어떻게 반응하나?"

- 그래픽과 규모로 상용 게임과 경쟁하지 않습니다.
- 우리 동네의 도로·건물·지형을 그대로 불러옵니다.
- 시민은 3계층으로 나눕니다.
  - 대중 시민 수만 명: 규칙 기반으로 움직입니다.
  - 대표 페르소나 수백 명: LLM이 생활 패턴 템플릿을 만들고, 대중 시민이 재사용합니다.
  - 시장 보좌관·뉴스: LLM이 도시 통계를 읽고 설명합니다.
- 비싼 LLM은 생각을, 값싼 규칙은 실행을 맡습니다.

참고: [AgentSociety](https://github.com/tsinghua-fib-lab/AgentSociety), [A/B Street](https://github.com/a-b-street/abstreet)
