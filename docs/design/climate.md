# 기후 변화 시스템 설계

- 상태: 초안 v0.1 (2026-11-27, 기획)
- 결정 기록: [ADR 0003](../adr/0003-climate-system.md)
- 근거 목록: [research-log.md](research-log.md)

## 결론

기후 변화는 **동네가 겪는 위험(적응)** 으로 다룹니다. 1차 범위는 **폭염**과 **집중호우 침수** 두 가지이고, 둘 다 동네의 땅(포장·녹지·지형)과 시민 구성(고령자·반지하 가구)에 따라 피해가 달라지게 만듭니다.

## 왜 폭염과 침수인가

| 위험 | 한국 동네 규모의 근거 | 게임에서 보여 줄 것 |
| --- | --- | --- |
| 폭염 | 2024년 온열질환자 2,890명(5/20~8/19), 2011년 감시 시작 이래 두 번째. 최다는 2018년 4,526명·사망 48명. 환자의 78.5%가 실외 발생 (질병관리청 응급실 감시체계, 주간경향 2024-08-20 보도) | 같은 동네 안에서도 포장 많은 블록과 나무 많은 블록의 체감 차이, 야외 노동자·고령자 위험 |
| 집중호우 침수 | 2022-08-08 동작구 신대방동 1시간 141.5mm(비공식 관측), 서울 일 강수 381.5mm로 1907년 관측 이래 최고. 관악구 반지하 주택에서 3명 사망 (Korea Herald, 2022-08-10) | 지형 저지대·불투수면·하수 용량에 따른 침수, 반지하 가구 피해 |

**1차에서 제외한 것과 이유**

- 해수면 상승: 해안 동네에만 해당. 대상 동네가 해안이면 2단계 이후 모드로 추가합니다.
- 가뭄·산불·태풍 강풍: 동네 규모에서 정책으로 바꿀 수 있는 여지가 작거나, 모델이 커집니다.
- 동네 정책이 지구 기온을 바꾸는 것: 동네 하나의 배출량은 전 지구 기후에 측정 가능한 영향을 주지 않으므로, 그렇게 만들면 잘못된 인과를 가르치게 됩니다. 대신 탄소 배출은 정보 지표로만 보여 줍니다.

## 기후 시나리오 (외부 입력)

- 게임 시작 연도의 기후와 미래 추세는 **시나리오 파일**에서 읽습니다. 동네 정책은 시나리오를 바꾸지 못합니다.
- 시나리오는 IPCC SSP 경로를 따릅니다. 기본 난이도는 SSP2-4.5(중간), 어려움은 SSP5-8.5(고배출)입니다.
- 시나리오 파일이 담는 값 (연 단위): 여름 일 최고기온 분포, 폭염일수, 1시간 최대 강수량 분포.
- 데이터 출처 후보와 라이선스는 아래 "데이터"를 보세요. 실제 값을 넣기 전까지는 `synthetic` 시나리오(값을 임의로 정했다고 명시)를 씁니다.
- 파일 형식: [schema/climate](../../schema/climate/README.md) (2단계 #38). 예시 `synthetic.json`은 값을 임의로 정한 것이고, 기상청 ASOS 실측 사건은 API 활용 승인 후 넣습니다.

## 폭염 모델 (격자)

지형 데이터와 같은 30m 격자 셀마다 그날의 **체감 기온 보정값**을 계산합니다.

```
셀 기온 = 시나리오 일 최고기온
        + 열섬 가산(불투수 비율, 건물 밀도)
        − 냉각(나무 수관 비율, 공원·수변, 쿨루프)
        → 주변 셀로 일부 확산 (냉각 효과가 블록 너머로 번짐)
```

**냉각 기본값과 근거** (모두 조정 가능한 파라미터, 과장하지 않도록 문헌 범위의 보수적인 쪽을 기본값으로)

| 조치 | 기본 냉각 (셀 100% 적용 시) | 문헌 범위 |
| --- | --- | --- |
| 가로수·나무 수관 | −1.5 °C | 가로수 주간 기온 최대 1.5 °C 저감 (Coutts et al., Kumar et al. 2024에서 인용). 가로수 냉각 3.8 ± 3.1 °C (Kumar et al. 2024 메타분석). 보행자 높이 최대 12 °C (Li et al. 2024) |
| 공원·녹지 | −1.0 °C | 녹지 유형별 냉각 범위 (Kumar et al. 2024) |
| 수변·습지 | −1.5 °C | 습지 4.9 ± 3.2 °C (Kumar et al. 2024) |
| 혼합 수종 식재 | 나무 효과 +0.5 °C 추가 | 상록·낙엽 혼합이 단일 수종보다 약 0.5 °C 더 냉각 (Li et al. 2024) |
| 쿨루프 | 미정 | 아직 수치 근거를 확보하지 못함 → 조사 과제 |

**시민 영향**: 셀 기온이 위험 임계(시나리오의 폭염 기준)를 넘으면, 그 셀에서 시간을 보내는 시민의 건강 위험이 오릅니다. 고령자와 실외 노동 시민은 가중치를 더 줍니다(실외 발생 78.5%가 근거). 무더위 쉼터 반경 안 시민은 위험이 줄어듭니다.

## 침수 모델 (격자)

```
1. 셀 유출량 = C × 강우강도 × 셀 면적         (합리식, Q = CiA)
2. 하수 처리: 도로 셀은 하수 용량만큼 빼냄
3. 남은 물은 DEM 경사를 따라 가장 낮은 이웃으로 이동 (D8 흐름 방향)
4. 고인 물 깊이가 임계를 넘으면 그 셀 건물·차량·시민 피해
```

**유출계수 C 기본값** (Iowa DOT 설계 매뉴얼 4A-5 표, 5년 빈도 값 기준)

| 토지 피복 | C |
| --- | --- |
| 포장·건물 지붕 | 0.94 |
| 상업 지역 (불투수 85%) | 0.81 |
| 연립 주거 (불투수 65%) | 0.66 |
| 단독 주거 (불투수 40%) | 0.48 |
| 잔디 (경사 0~2%) | 0.22 |
| 공원 (불투수 8%) | 0.21 |

C는 미국 설계 기준 값이므로 한국 하수도 설계 기준 값으로 바꿀 수 있는지 조사 과제로 남깁니다.

**시민 영향**: 반지하 가구는 같은 수심에서 피해 확률을 크게 둡니다(2022년 사망 사례 근거). 침수된 도로는 교통 그래프에서 통행 불가로 바뀌어 이동 시간 지표에 바로 반영됩니다.

## 정책 카드 (기후)

| 정책 | 효과 경로 | 비용 성격 |
| --- | --- | --- |
| 가로수 심기 | 폭염 냉각, 유출 소폭 감소 | 설치 + 유지비, 효과는 수년에 걸쳐 커짐 |
| 포켓 공원 | 냉각, 유출 감소 | 땅 확보 필요 |
| 투수성 포장 | 유출계수 감소 | 도로 재포장 |
| 빗물 저류조 | 하수 용량 보완 | 큰 초기 비용 |
| 하수관 용량 증설 | 처리 가능 강우강도 상승 | 매우 큰 비용, 공사 중 교통 차단 |
| 반지하 이주 지원 | 침수 인명 피해 감소 | 지속 보조금, 주거 수요 변화 |
| 무더위 쉼터 | 폭염 건강 위험 감소 | 운영비 |
| 폭염 시 야외 작업 제한 | 노동자 위험 감소 | 상권·만족도 하락 |
| 쿨루프 보조금 | 냉각 (수치 미정) | 보조금 |

모든 정책에는 **비용 + 부작용**이 있어야 합니다. 정답 하나가 없는 선택이 정책 게임의 핵심입니다.

## AI 시민과 보좌관의 역할

- **대중 시민 (규칙)**: 셀 기온·수심에 따라 경로와 외출을 바꿉니다.
- **페르소나 (LLM)**: "반지하 거주 1인 가구", "택배 기사", "경로당 어르신" 같은 대표 인물이 사건 뒤 반응과 요구를 말합니다. 발언은 시뮬 통계에서 만들어진 사실만 근거로 씁니다.
- **보좌관 (LLM)**: 사건 브리핑에서 "어느 블록이 왜 뜨거웠는지/잠겼는지"를 셀 데이터와 함께 설명하고, 정책 선택지를 비용·부작용과 함께 제시합니다. 추천은 하되 결정은 플레이어가 합니다.
