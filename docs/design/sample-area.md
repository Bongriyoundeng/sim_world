# 샘플 동네: 평택역 원도심 (통복천 일대)

- 상태: 확정 (2026-11-27). 도시는 리드가 평택시로 정했고, 구역은 기획이 아래 근거로 골랐습니다.
- 결정 기록: [ADR 0005](../adr/0005-sample-area.md)

## 구역

| 항목 | 값 |
| --- | --- |
| 이름 | `pyeongtaek-station` |
| 포함 동네 | 평택역 주변 원평동·통복동·비전1동 일부, 통복천 구간 |
| 중심 | 북위 36.993, 동경 127.087 (OSM 확인 후 조정 없음) |
| 크기 | 1.5 km × 1.5 km |

2026-11-27 Overpass 조회로 확인한 결과, 이 중심에서 평택역(OSM node 354373659 "평택")은 중심에서 서쪽 약 150m·남쪽 약 240m에 있고, 통복천(OSM way 425789115)은 구역 안을 약 560m 지나갑니다. 둘 다 들어가므로 중심을 옮기지 않았습니다. 확인 명령: `cd gis && uv run python -m dongne_gis check --lat 36.993 --lon 127.087 --size 1500`

## 고른 이유

| 기준 | 이 구역의 근거 |
| --- | --- |
| 침수 위험이 실제로 있다 | 2024-07-18 집중호우 때 통복천 범람 우려로 통복동 6·7통 저지대 주민이 대피했고, 평택시 피해 306건, 관리 지하차도 15곳 중 8곳이 잠겼다 ([아주경제 2024-07-19](https://www.ajunews.com/view/20240719172841559)). 2026-07-09에도 통복천 수위 상승, 이동동 지하차도 배수 불량, 통복동 화촌길 도로 침수가 신고됐다 ([경기일보 2026-07-09](https://www.kyeonggi.com/article/20260709580088)). 7~9일 비전2동 누적 214mm, 최대 시간당 54.5mm, 피해 69건 ([뉴시스 via 파이낸셜뉴스 2026-07-10](https://www.fnnews.com/news/202607101058470134)) |
| 폭염 위험이 실제로 있다 | 평택시 전역 CFD 분석에서 비전동이 열환경 취약 지역 3곳(비전동·포승읍·지산동) 중 하나로 꼽혔고, 분석 구역에서 1.5m 높이 35 °C 초과 면적이 50%를 넘었다 (강준석 외, 한국방재학회 논문집 24(6), 2024) |
| 정책 갈등이 있다 | 신도시(고덕국제신도시 등) 개발과 동시에 평택역 원도심이 쇠락하는 현상, 평택역 광장·원평동 역세권·평택1구역 재개발이 진행 중 ([프레시안 2023-09-22](https://pressian.com/pages/articles/2023092110394255974)) → "재개발 vs 기존 주민", "녹지 vs 개발" 선택이 자연스럽게 생김 |
| 교통 데모에 맞는다 | 평택역(철도) 중심의 도로망과 상권 → 1단계 도로·구역·차량 데모 소재 |
| 범위가 데모에 맞다 | 1.5km 사방은 30m 지형 격자로 50 × 50 셀, 차량 수천 대 규모로 1단계 성능 목표에 맞음 |

## 데이터 확인 과제

- [x] 평택역과 통복천이 구역 안에 모두 들어가는지 OSM으로 확인 (2026-11-27, 중심 조정 없음)
- [x] OSM에서 구역 안 건물·도로 수와 건물 층수(`building:levels`) 채움 정도 확인 (2026-11-27 OSM 기준, [maps/pyeongtaek-station](../../maps/pyeongtaek-station/README.md))
  - 도로: OSM highway way 862개 (구역 경계에서 잘라 LineString 882개). 많은 순서로 footway 225, residential 223, service 218, secondary 76, tertiary 61
  - 건물: 3048개 (`building=yes` 2944, `apartments` 69, `school` 15)
  - `building:levels` 채움: 3048개 중 3개 (0.1%), `height`: 0개 → 층수는 거의 비어 있어 건물 높이는 용도·면적 기반 기본값이 필요함 (이슈 #13 밸런스에서 정함)
- [x] Copernicus DEM에서 통복천 저지대가 30m 해상도로 드러나는지 확인 (2026-11-27, `dongne_gis check`)
  - 구역 고도 2.9~47.1 m, 전체 50×50 셀 평균 12.4 m
  - 통복천(OSM way 425789115)이 지나는 셀 24개의 평균 6.3 m → 전체 평균보다 6.2 m 낮아 저지대가 드러남
  - 주의: Copernicus DEM은 건물·나무 높이가 섞인 지표면 모델(DSM)이라 시가지 셀 고도가 실제 지면보다 높게 나올 수 있음. 침수 모델 정밀도에 영향이 있으면 2단계에서 지면 모델(DTM) 보정을 검토
- [ ] 2024-07-18 강우 기록을 침수 모델 검증 사례로 쓸 수 있는지 기상청 AWS 자료 확인 (기사 속 "시간 평균 168.7mm" 표현은 의미가 모호해 인용하지 않음)
