# 핵심 게임 흐름

- 상태: 초안 v0.1 (2026-11-27, 기획)
- 근거: [research-log.md](research-log.md)

## 한 줄 정의

플레이어는 **우리 동네의 구청장**이 되어 정책을 고르고, AI 시민이 그 정책에 어떻게 반응하는지 계절 단위로 지켜봅니다.

## 루프

1. **관찰** — 지도(교통·열·침수 레이어), 5대 지표, 시민 목소리(페르소나 발언)를 봅니다.
2. **결정** — 예산 안에서 정책 카드를 고르거나 도로·구역·시설을 배치합니다.
3. **진행** — 시뮬레이션이 한 계절(약 90일)을 진행합니다. 폭염·집중호우 같은 기후 사건이 이 사이에 일어납니다.
4. **브리핑** — AI 보좌관이 "무엇이 일어났고 왜 그랬는지"를 지도 위 근거와 함께 설명합니다.
5. 다음 계절로 돌아갑니다.

브리핑을 루프의 정식 단계로 둔 이유: 기후 적응 시리어스 게임 연구에서 학습은 대부분 게임 뒤의 되돌아보기(debriefing)에서 일어나고, 복잡도가 높으면 개별 조치의 결과를 파악하기 어렵다는 점이 핵심 과제로 꼽혔습니다 (Neset et al., 2020). 그래서 원인과 결과를 보좌관이 명시적으로 짚어 주는 단계를 넣습니다.

## 시간 단위

| 단위 | 용도 |
| --- | --- |
| 틱 = 1분 (게임 내) | 차량 이동, 침수 확산 |
| 하루 | 시민 일과(통근·쇼핑·귀가), 일 최고기온 |
| 계절 (90일) | 플레이어 결정 주기, 예산 집행 |
| 년 | 기후 시나리오 갱신, 인구 이동, 세수 |

플레이어는 계절 단위로만 결정하므로 분 단위 시뮬은 "빨리 감기"로 보여 줍니다.

## 5대 지표

| 지표 | 무엇으로 계산하나 | 단계 |
| --- | --- | --- |
| 이동 시간 | 시민 평균 통근 시간 | 1단계 |
| 재정 | 세수 − 지출, 누적 부채 | 2단계 |
| 시민 만족도 | 페르소나·대중 시민 만족도 평균 | 2단계 |
| 기후 안전 | 폭염 위험 노출 인구, 침수 피해 가구 | 2단계 (기후) |
| 탄소 배출 | 교통·건물 에너지 추정치 (정보용) | 2단계 이후 |

지표가 5개를 넘지 않게 유지합니다. 새 지표를 넣으려면 기존 지표 하나를 빼거나 합쳐야 합니다.

## 범위 밖 (의도적으로 하지 않음)

- 도시 전체(수십 km) 규모, 고층 건물 세밀 그래픽
- 전쟁·재난 파괴 연출
- 동네 정책으로 전 지구 기후를 바꾸는 설정 (이유: [climate.md](climate.md))
