# 정책 목록

- 상태: 초안 v0.1 (2026-11-27, 기획)

정책은 단계별로 나눠 넣습니다. 각 단계에서 쓸 수 있는 정책은 그 단계의 시뮬 모델이 효과를 실제로 계산할 수 있는 것만 둡니다(효과가 없는 카드는 넣지 않음).

| 단계 | 정책·도구 | 효과를 계산하는 모델 |
| --- | --- | --- |
| 1단계 | 도로 건설·철거, 일방통행, 속도 제한 | 도로 그래프 + 차량 경로 |
| 1단계 | 구역 지정 (주거·상업·업무·공원) | 통근 수요 생성 |
| 2단계 | 버스 노선, 주차 요금 | 수단 선택 |
| 2단계 | 재산세율, 상권 지원금 | 재정·경제 |
| 2단계 (기후) | 가로수, 포켓 공원, 투수성 포장, 빗물 저류조, 하수관 증설, 반지하 이주 지원, 무더위 쉼터, 폭염 시 야외 작업 제한, 쿨루프 보조금 | [climate.md](climate.md) 폭염·침수 모델 |
| 3단계 이후 | 주민 참여 예산, 모드가 추가하는 정책 | — |

## 정책 카드 공통 형식

```yaml
id: street-trees
name: 가로수 심기
cost: { install: 0, upkeep_per_year: 0 }   # 값은 밸런스 단계에서
targets: road_cells                        # 적용 대상
effects:
  - model: heat
    param: tree_canopy_fraction
    change: +0.3
    ramp_years: 5                          # 나무가 자라는 시간
side_effects:
  - 공사 기간 도로 차선 축소
evidence: research-log.md#heat-trees       # 근거 링크 필수
```

`evidence`가 없는 정책은 PR에서 받지 않습니다.
