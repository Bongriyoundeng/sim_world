# ADR 0008: 2단계 데이터 출처 — 인구·건물·지가·기상

- 상태: 확정 (2026-11-28, 이슈 #35)

1. **인구는 행정안전부 행정동 CSV**를 기준으로 합니다. 셀 단위 인구는 이 동 합계를 건물(주거 용도·바닥 면적·층수)에 비례해 나눠 추정합니다(#36).
2. **건축물대장은 서비스 키가 있어야** 씁니다. 키 발급은 공공데이터포털 회원 가입·활용 신청이 필요해 관리자가 직접 합니다(이 저장소의 자동화가 계정을 만들지 않음). 키가 없으면 지금처럼 OSM 건물 + 표시 높이 가정([building-height](../design/research-log.md#building-height))으로 대신합니다. 키는 환경변수로만 받고 커밋하지 않습니다.
3. **개별공시지가는 파일 자료**를 data-raw/에 받아 구역 셀로 집계합니다(#37). 원본은 커밋하지 않고, 셀 집계값과 출처만 맵 패키지에 넣습니다.
4. **SGIS는 보류**합니다. 이용약관과 저작권 정책이 다르게 읽히고 자료마다 공공누리 유형을 확인해야 해서, 행정안전부·국토교통부 자료로 충분한 동안은 쓰지 않습니다. 쓰려면 그 자료의 공공누리 표시(제1유형인지)를 확인하고 이 ADR을 고칩니다.
5. 공공데이터포털 자료의 표시는 "이용허락범위 제한 없음"이며 공공누리 유형은 적혀 있지 않습니다. 출처 표기는 의무로 적혀 있지 않아도 **항상 남깁니다**(ATTRIBUTION.md, 맵 패키지 `attribution`).

## 이유

- 행정동 인구는 1세 단위 연령까지 있어 폭염 고령자 가중(climate.md)과 통근 인구 추정에 바로 쓸 수 있고, 이용 제한이 없다고 명시되어 있습니다.
- 건축물대장은 층수·용도를 줄 수 있지만(층별개요·표제부) 좌표가 없어 OSM 건물과 지번으로 맞춰야 하고, 키가 필요합니다. 그래서 필수가 아닌 보정 자료로 둡니다. 세대 수·주용도가 응답에 어떤 필드로 오는지는 샘플 응답으로 확인해야 합니다.
- 공시지가는 필지 단위라 30 m 셀로 집계하기에 해상도가 충분합니다.

## 검토한 대안

- SGIS 집계구·격자 인구: 공간 해상도는 가장 좋지만 이용 조건 확인 전에는 쓰지 않음.
- KOSIS 주민등록인구 표: 표 페이지가 로그인으로 넘어가 확인하지 못했고, 같은 원자료(행정안전부)를 공공데이터포털에서 받을 수 있어 대신함.
- 인구를 전부 가정값으로 둠: 1단계 방식. 2단계 목표(동네 단위 지표)에 맞지 않음.

## 결과

- data-sources.md 표와 ATTRIBUTION.md에 채택한 자료를 추가합니다.
- #36(인구)은 행정안전부 CSV로 시작하고, 건축물대장 키는 관리자에게 요청 사항으로 남깁니다.
- 원본 파일·API 응답은 data-raw/에만 두고 커밋하지 않습니다.
