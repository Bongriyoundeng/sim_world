# ADR 0004: 1단계 교통 시뮬레이션 방식

- 상태: 확정 (2026-11-27, 기획. 시뮬 코어 담당이 구현 중 수정 가능)

## 결정

1단계 차량 이동은 **이벤트 기반 + 차선 대기열(queue) 모델**로 만듭니다. 가감속과 차선 중간 추월은 넣지 않습니다.

## 이유

- 목표는 "도로를 바꾸면 통근 시간이 어떻게 바뀌나"를 보여 주는 것이고, 정확한 차량 궤적은 필요 없습니다.
- A/B Street는 0.1초 단위 갱신에서 이벤트 방식으로 옮기며 속도와 단순함을 얻었고, 부드러운 가감속이 핵심 가치를 더하지 않았다고 기록했습니다.
- FHWA는 미시 모델이 보정할 파라미터가 많다고 지적합니다. 기여자가 적은 초기에 보정 부담을 피합니다.
- 결정론적 코어(ADR 0002)와 이벤트 큐는 잘 맞습니다. 같은 입력이면 같은 이벤트 순서가 나옵니다.

## 검토한 대안

- 0.1초 미시 모델(IDM 등): 시각적으로 자연스럽지만 느리고 보정 부담이 큼. 화면 연출은 클라이언트에서 보간으로 대신합니다.
- 거시 모델(링크 단위 속도-교통량): 가장 빠르지만 "차가 움직이는 GIF"를 만들 수 없음.

## 결과

- 교차로 신호·우선순위 규칙이 코어의 주요 작업이 됩니다.
- 침수 셀은 해당 차선을 "통행 불가"로 바꾸는 이벤트로 연결됩니다 (ADR 0003).
