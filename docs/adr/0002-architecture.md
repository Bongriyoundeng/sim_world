# ADR 0002: 모노레포와 코어 언어

- 상태: 확정 (2026-11-27)

## 결정

- 저장소 하나에 팀마다 최상위 폴더 하나를 둡니다.
- 시뮬레이션 코어는 Rust 라이브러리로 만듭니다.
- Godot은 GDExtension(godot-rust/gdext)으로, Python은 PyO3로 같은 코어를 프로세스 안에서 불러 씁니다.

## 이유

- 초기 2~3명 규모에서 저장소를 나누면 관리 부담만 늘어납니다.
- Rust는 메모리 안전성과 간단한 빌드로 기여자 진입장벽이 낮고, 바인딩 두 개를 같은 언어로 만들 수 있습니다.
- 프로세스 안 바인딩은 별도 서버보다 구조가 단순하고 배포 파일이 적습니다.

## 검토한 대안

- C++ 코어 (godot-cpp, pybind11)
- 코어를 별도 서버 프로세스로 두고 메시지로 통신
