# ADR 0003: 기후 변화 시스템 범위

- 상태: 확정 (2026-11-27, 기획. 리드가 사후 검토)

## 결정

1. 기후 변화는 동네가 겪는 위험에 대한 **적응**으로 다룹니다. 동네 정책은 기후 시나리오를 바꾸지 못합니다.
2. 1차 위험은 **폭염**과 **집중호우 침수** 두 가지입니다.
3. 두 위험 모두 지형과 같은 **30m 격자**에서 계산합니다.
4. 미래 기후는 **SSP 시나리오 파일**로 넣습니다. 기본은 SSP2-4.5입니다.
5. 모델 계수는 모두 근거 문헌이 있는 값을 기본값으로 쓰고, 근거가 없으면 "조사 과제"로 남깁니다.

## 이유

- 한국 도시에서 최근 인명 피해가 큰 기후 위험이 폭염(2024년 온열질환자 감시 이래 두 번째)과 도시 침수(2022년 서울 반지하 사망)입니다.
- 둘 다 동네 단위 정책(녹지, 포장, 하수, 주거 지원)으로 피해가 달라지므로 "정책 → 시민 반응"이라는 게임 목표에 맞습니다.
- 동네 하나의 배출이 전 지구 기온을 바꾸는 설정은 잘못된 인과를 보여 줍니다.
- 30m 격자는 이미 쓰는 Copernicus DEM과 해상도가 같아 별도 데이터 없이 시작할 수 있습니다.
- 기후 시리어스 게임 연구는 복잡도가 높으면 개별 조치의 결과를 이해하기 어렵다고 지적합니다. 위험을 두 개로 제한하는 이유입니다.

## 검토한 대안

- 해수면 상승 포함: 해안 동네에만 의미가 있어 모드로 미룸.
- 기후를 배경 연출로만 표현: 정책과 연결되지 않아 게임 목표와 맞지 않음.
- 물리 기반 미기후 모델(ENVI-met 등): 정확하지만 실시간 게임에 너무 무겁고 라이선스 확인이 필요.

## 결과

- 시뮬 코어에 격자 레이어(`heat`, `water`)가 생깁니다. 2단계 작업입니다.
- 맵 패키지에 토지 피복 레이어(불투수 비율, 나무 수관 비율)가 필요합니다. 1단계 GIS 작업에 넣습니다.
