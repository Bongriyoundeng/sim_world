# ADR 0005: 샘플 동네

- 상태: 확정 (2026-11-27)

## 결정

첫 샘플 맵은 **평택시 평택역 원도심, 통복천 일대 1.5km 사방**(`maps/pyeongtaek-station`)으로 합니다.

## 이유

침수(통복천, 2024·2026년 실제 피해), 폭염(비전동 열환경 취약 지역), 재개발 갈등(원도심 쇠락과 역세권 개발), 교통(평택역)이 한 구역에 모두 있어 1단계 교통 데모와 2단계 기후 시스템을 같은 맵으로 검증할 수 있습니다. 근거는 [design/sample-area.md](../design/sample-area.md).

## 결과

- 실제 침수 사례(2024-07-18)를 침수 모델 검증용 시나리오로 쓸 수 있는지 조사합니다.
- 고덕국제신도시는 2단계 비교 맵 후보로 남깁니다.
