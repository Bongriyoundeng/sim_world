# ADR 0001: 라이선스

- 상태: 확정 (2026-11-27)

## 결정

코드는 GPL-3.0-or-later, 아트·문서는 CC BY-SA 4.0, 맵 데이터는 ODbL 1.0을 씁니다.

## 이유

- 누군가 포크해서 소스를 닫고 재배포하는 것을 막습니다.
- Godot(MIT)과 주요 Rust/Python 의존성이 모두 GPL-3.0과 호환됩니다.

## 검토한 대안

- MPL-2.0: 파일 단위 공개 의무라 더 느슨하고 콘솔 배포가 가능하지만, 소스를 닫은 파생작을 막는 힘이 약합니다.

## 결과

- 콘솔 배포는 하지 않습니다.
